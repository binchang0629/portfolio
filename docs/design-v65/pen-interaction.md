# 펜 이동과 관성

내장 imagegen으로 기존 메모 이미지에서 펜과 펜 그림자를 지운 투명 이미지, 별도의 파란 펜 투명 에셋을 만들었습니다. 기존 이미지들은 보존합니다.

- public/assets/background/desk-memo-without-pen-v7.png
- public/assets/desk/pen-isolated-v1.png

최종 편집 요청: 메모 이미지에서는 펜과 푸른 그림자 얼룩을 완전히 제거하고 흰 종이와 줄을 복원. 펜 에셋에서는 종이·책·주변 그림자·푸른 빛 번짐을 제거하고 파란 몸통, 클립, 금속 펜촉과 반사만 유지. 실제 알파 배경을 확인했습니다.

펜은 독립된 Motion 요소입니다. 책상 범위 안에서 드래그하고 놓은 속도에 따라 미끄러집니다. 접지 그림자는 CSS로 적용되어 이동할 때 같이 따라갑니다. 동작 줄이기 설정은 관성을 끕니다. 방향키로 이동할 수 있고 배치 초기화로 제자리로 돌아갑니다. 메모의 글은 기존 HTML을 유지합니다.

빠르게 놓으면 속도에 따라 이동과 회전이 이어지고 마찰로 서서히 멈추도록 조정했습니다. 회전한 펜의 전체 크기로 책상 경계를 계산하고, 경계에 닿으면 에너지를 줄입니다. 다시 잡으면 관성이 바로 멈춥니다.

## 입체 구르기

몸통·금속 펜촉·노크 버튼·클립을 실제 3D 메시로 분리했습니다. 이동 거리와 몸통 반지름으로 축 회전량을 계산합니다. 클립은 회전하며 앞뒤로 넘어가고, 입체 조명과 반사가 변합니다. 정지 상태에서는 재렌더링하지 않습니다. WebGL이 없으면 기존 투명 PNG로 표시합니다.
