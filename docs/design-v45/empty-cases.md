# V45 꺼낸 테이프와 빈 케이스 구분

- 마우스·터치 재현에서 꺼낸 테이프는 보관 목록과 개수에서 제외됨을 확인.
- 빈 케이스의 책등 종이와 라벨을 12% 투명도로 바꾸고 중앙 EMPTY 표시. 차 있는 케이스와 시각적으로 구분.
- 화면 개수를 "테이프 N개 보관"으로 명시. 목록에서도 빈 케이스는 개수에 포함되지 않음을 안내.
- 드래그 뒤 늦게 전달될 수 있는 클릭이 빈 케이스에 테이프를 다시 넣지 않도록, 해당 클릭을 소비하거나 다음 명시적 포인터 시작까지 차단.
- 별도의 클릭·키보드 조작으로 빈 케이스에 다시 넣는 기능은 유지.
