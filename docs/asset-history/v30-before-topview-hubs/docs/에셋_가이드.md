# 에셋 가이드 · V29

작업 폴더: C:/bin/portfolio. 파스텔 책상과 흰 플레이어의 방향을 기준으로 독립 탑뷰 카세트 원본을 만들었습니다. 다섯 카세트는 공통 원본을 공유하고 책상 위 회전, 색, 감긴 양만 다릅니다.

## 활성 파일

```text
public/assets/
  background/desk-topview-v1.png

src/assets/
```

활성 재질은 PNG 6개와 SVG 스티커 5개입니다. PNG는 카세트·플레이어·책상 1536×1024, 보관함 1440×1092입니다. 원본 주변에 배경이나 알파 가장자리 잡음이 남아 있어 외곽 SVG 마스크로 사물 영역만 표시합니다. 실제 WebGL 3D 모델이나 순수 벡터 에셋은 아닙니다.

## 공통 카세트와 릴

CassetteSurface.jsx가 책상과 플레이어 안에서 같은 카세트를 조립합니다. clean-v1.png는 빈 내부와 외피, 원본 render-v1.png는 사진 허브와 검정 코일 표면을 제공합니다. 종이 위 문구와 스티커는 실제 SVG 텍스트·벡터입니다.

- topview-geometry.js에서 외곽, 종이, 내부 창, 두 허브의 좌표를 관리합니다.
- 좌우 허브 중심은 (469,441), (1068,441)이며 원형 마스크 반지름은 109입니다.
- 코일 표면을 샘플링할 때 원본 허브와 그 아래 회색 초승달 테두리는 반지름 128 마스크로 먼저 제외합니다. 감긴 양에 따라 허브가 확대되어 중복 테두리로 나타나지 않습니다.
- 두 코일은 같은 중심의 검정 동심원과 사진 표면을 조합하고, 중간 공간을 가로지르는 리본은 그리지 않습니다.
- 플레이어 안에서는 균일 배율 392/599와 평행 이동만 적용합니다. 가로·세로 비율을 달리하거나 릴을 찌그러뜨리지 않습니다.
- 1440px 검수 화면에서 삽입·책상 카세트의 배율 비는 0.99629, 두 릴 축의 위치 오차는 0.001px 미만입니다.
- 삽입 상태는 기존 플레이어 문틀로 가려집니다. 본체와 실제 기계식 버튼의 재질은 그대로 유지합니다.

회전·감김은 src/lib/tape-mechanism.js 및 useTapeTransport.js에서 제어합니다. 사진 기반 조명 반사는 물리적으로 다시 계산하지 않습니다.

## 독립 보관함

ArchiveTray.jsx에는 floor, stored-tapes, inner-shadow, rim, dividers 레이어가 있습니다. 같은 사진을 SVG 영역별로 표시하고 안쪽 그림자는 별도 벡터로 추가합니다. 바깥 접지 그림자는 책상 좌표의 CSS에서 처리하며 회전하는 사물의 내부로 넣지 않습니다.

5칸 함은 책상 위 테이프 한 개와 비슷한 가로 크기, 약 0.8배의 세로 크기입니다. 넓은 앞면 패널 대신 윗테두리에 MORE TAPES 라벨을 놓았습니다. 보관함에 실제 추가 작업이 생기면 세워 꽂힌 테이프는 얇은 등 부분으로 표시합니다. 현재 archiveTracks는 비어 있으므로 가짜 작업이나 중복 카테고리 테이프는 표시하지 않습니다.

보관함에서 꺼낸 추가 작업을 삽입하면 책상에서 사라집니다. 꺼내거나 다른 작업으로 교체하면 보관함으로 돌아옵니다. 반환 순간을 입체적으로 감추는 별도 이동 애니메이션은 아직 추가하지 않았습니다.

## 책상과 문구

desk-topview-v1.png는 책상·노트·메모·펜을 포함하는 정적 배경입니다. 이전 큰 보관함은 배경에서 제거하고 독립 사물로 옮겼습니다. 노트·메모·펜 전체가 개별 투명 PNG나 벡터로 분리된 것은 아닙니다. 글자와 클릭 영역은 React입니다. 다섯 테이프의 위치·회전·색·감긴 양은 src/data/portfolio.js에서 수정합니다.

## 확인과 과정 보존

`npm run lint`, `npm run build`, `npm run check:assets`로 코드와 파일을 확인합니다. 실제 동작·모바일·축 및 배율 검수는 docs/design-v29/refinement-v29-qa.json에 있습니다. 생성 방식은 내장 image_gen이며 생성 프롬프트와 파일 경로는 docs/design-v29/imagegen-topview-v29.json에 기록했습니다.

이전 카세트 재질·큰 보관함 배경과 구현은 docs/asset-history/v27-before-shared-camera, v28-before-topview-assets, v29-retired-assets에 보존합니다. V27~V28의 코드와 검수 자료를 현재 에셋과 혼동하지 않도록 구분합니다.
