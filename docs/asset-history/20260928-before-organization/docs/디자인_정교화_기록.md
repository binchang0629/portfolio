# 디자인 정교화 · V23

## 목표

승인된 V2 파스텔 책상 구도와 현실적인 재질을 유지하면서 글자, 릴 중심, 부품 비례와 빛을 정리합니다. AI 사용을 숨긴다는 의미가 아닌 시각적 오류와 일관성을 개선하는 작업입니다.

## 이번 변경

- 전체 화면 이미지에 포함됐던 글자를 실제 HTML·SVG 텍스트로 분리.
- 카세트 케이스는 하나의 기존 분리 에셋을 공유해 동일 구조와 규격 유지.
- 검정 코일은 흰 릴과 같은 중심을 가진 벡터 원으로 구성. 좌우 코일 사이에는 가로 테이프를 그리지 않음.
- 다섯 테이프의 감긴 양을 다르게 설정. 감기 동작에서 두 코일의 면적 합을 유지.
- 라벨·보조 문구·스티커는 읽을 수 있는 실제 텍스트와 벡터로 배치.
- 케이스 채도를 낮추고, 그림자 방향과 강도를 통일.
- 흰 플레이어의 실제 재질은 V2 이미지에서 분리해 유지. 제어 버튼은 오른쪽에 배치.
- 헤드셋을 제거하고 빈 카세트 보관함 복원. 펜 유지. 화분·커피·사진은 제거 상태 유지.
- 복잡한 잎 그림자를 줄인 배경으로 교체.
- 기본 카테고리 테이프와 추가 작업 보관함을 구분. 현재 추가 작업 목록은 비어 있으며 가상의 작업을 만들지 않음.

## 에셋 구조

배경: assets/desk/desk-refined-v4-archive.png. 노트·메모·펜·빈 보관함의 정적 재질 레이어.

카세트: 기존 현실적인 PNG 재질 + 벡터 코일·마스크·스티커 + 실제 텍스트의 혼합 구조. 모든 사물을 순수 벡터로 변환한 것은 아닙니다.

플레이어: 원본 재질을 인라인 SVG 마스크로 분리해 개별 배치. 카세트 삽입부는 별도의 클리핑 영역.

## 배경 편집

방식: 내장 imagegen 이미지 편집. 이전 이미지와 소스는 보존.

프롬프트: 기존 파스텔 아이보리 탑뷰 책상에서 헤드셋을 제거하고 왼쪽 아래에 투명한 빈 카세트 보관함을 배치한다. 동일 간격의 칸막이와 일정한 벽 두께, 자연스러운 접지 그림자를 가진 실제 제조물처럼 정리한다. 노트·메모·파란 펜을 유지하고 노트의 시각적 비중을 줄인다. 과한 반사와 잎 그림자를 줄인 부드러운 빛으로 책상을 정리한다. 글자·아이콘·테이프·플레이어는 이미지에 넣지 않는다. 따뜻한 아이보리·라벤더 색감과 현실적인 재질을 유지한다.

## 남은 작업

- 실제 카세트의 금형·가이드 구멍·치형 등 제조 디테일을 모두 검증한 3D 모델은 아님.
- 각 색은 같은 케이스 원본의 색상 변형. 새로운 독립 렌더 에셋 5개를 만들지는 않음.
- 프로젝트의 대표 화면·링크·개인 역할 증빙은 기존 MD의 확인 필요 항목을 보완할 것.
- 보관함 추가 작업은 src/data/portfolio.js의 archiveTracks 목록에 실제 콘텐츠를 등록한 뒤 사용. 이미지 속 칸 수는 작업 수가 아님.
- 실제 음원 재생은 연결하지 않았으며, 현재 재생 버튼은 이야기와 릴 시각 효과를 제어.
