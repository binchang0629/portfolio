# 에셋 가이드 · V27

작업 폴더: C:/bin/portfolio. 현재 화면은 파스텔 책상, 다섯 카세트, 노트·메모·보관함과 한 렌더에서 표현한 흰 플레이어로 구성합니다.

## 현재 사용하는 파일

```text
public/assets/
  background/desk.png
  cassette/
    body.png · labels.png · window.png · hubs.png
    stickers/about.svg · team.svg · design.svg · branding.svg · next.svg
  player/coherent/
    render-v1.png
    empty-interior-v1.png
    clean-interior-v1.png
  manifest.json
src/assets/
  index.js
  cassette/geometry.json
  player/coherent-geometry.js
```

활성 에셋은 8개 PNG 재질과 5개 SVG 스티커입니다. PNG는 1536×1024 원본 좌표계를 유지하고 필요한 사물·부품 영역만 SVG 마스크로 표시합니다. 원본의 배경이 완전히 투명한 것은 아니며, 웹 화면에서 외곽 마스크로 제거합니다.

## 플레이어와 삽입 상태

IntegratedPlayer.jsx는 render-v1.png의 본체·물리 버튼·닫힌 유리 문틀을 사용합니다. 카세트와 플레이어를 따로 기울여 합성하지 않습니다. 함께 표현된 카세트가 수납부 안에 고정된 원근과 그림자를 유지합니다.

- render-v1.png: 모든 부품을 같은 장면에서 표현한 공통 재질. 흰 허브도 여기서 좌우 각각 분리합니다.
- empty-interior-v1.png: 같은 좌표의 카세트 없는 내부. 본체 전체를 교체하지 않고 내부 영역만 표시합니다.
- clean-interior-v1.png: 카세트 내부 창에서 코일과 흰 허브만 뺀 재질. 회전·감김 레이어의 바탕입니다.
- coherent-geometry.js: 본체 외곽, 카세트와 창의 마스크, 릴 중심, 실제 버튼의 클릭 위치.

흰 허브는 같은 렌더에서 가져온 사진 재질입니다. 코일도 같은 렌더의 검정 표면과 미세한 벡터 링을 조합합니다. 회전과 감긴 양은 src/lib/tape-mechanism.js에서 제어합니다. 검정 코일 사이에는 가로 테이프를 그리지 않습니다.

버튼은 렌더에 표현된 기계식 키의 위치에 투명한 HTML 클릭 영역을 연결합니다. 별도 평면 버튼 카드나 아이콘을 덮지 않습니다. 라벨과 설명은 실제 SVG·HTML 텍스트이며 콘텐츠를 직접 수정할 수 있습니다.

이 구성은 렌더 재질과 SVG 마스크를 사용하는 2D 웹 인터페이스입니다. 실제 WebGL 3D 모델이나 순수 벡터 플레이어는 아닙니다. 사진 기반 허브의 조명 반사를 물리적으로 다시 계산하지는 않습니다.

## 책상 위 테이프와 소품

Cassette.jsx는 공통 외피·흰 종이·내부 창·흰 허브 재질과 벡터 코일을 조립합니다. 다섯 테이프는 같은 규격을 공유하며 색과 감긴 양을 다르게 설정합니다. 삽입한 테이프는 책상에서 사라집니다.

노트·메모·펜·빈 보관함의 정적 재질은 desk.png 안에 포함돼 있습니다. 노트·메모·보관함의 글자와 클릭 영역은 React에서 별도로 구현합니다. 모든 소품이 개별 투명 PNG나 순수 벡터로 분리된 것은 아닙니다.

## 수정과 확인

- src/assets/index.js: 활성 파일 경로.
- public/assets/manifest.json: 파일 목록, 원본 크기와 제작 시점 해시.
- src/data/portfolio.js: 카테고리·문구·색·감긴 양과 보관함 추가 작업.
- src/data/projects.js: 실제 팀·개인 프로젝트 소개.

`npm run check:assets`로 파일 누락과 크기를 확인하고 `npm run lint`, `npm run build`로 화면 연결을 확인합니다. 파일을 교체할 때 index.js와 manifest.json도 함께 갱신합니다.

추가 실제 작업은 archiveTracks에 등록합니다. 보관함에서 꺼낸 테이프를 삽입하면 책상에서 사라지고, 꺼내거나 다른 테이프로 교체하면 보관함으로 돌아옵니다. 현재 추가 작업 목록은 비어 있습니다.
