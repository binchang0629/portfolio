# V48 플레이어 기준의 책상 시점

- 기존 플레이어 유지. 보관함의 수직 탑뷰와 책상 배경 소품의 시점 차이 수정.
- 플레이어를 카메라·조명 참고로 배경의 책·메모·펜을 편집. 얇은 앞쪽 두께, 완만한 종이 곡률, 같은 방향의 접지 그림자 적용.
- 보관함은 기존 사진 재질과 독립 SVG 칸·케이스 구조 유지. 앞쪽 벽을 별도 레이어로 추가.
- 책상에서 회전한 물체에 같은 세로 투영 적용. 보관함 회전과 칸 판정은 동일한 SVG 좌표에 연결.
- 늘어난 보관함 높이에 맞춰 클릭 영역 계산을 공통 viewport 값으로 변경.
- 이전 배경 파일과 변경 전 소스 보존. 실제 3D 모델이 아니라 사진과 벡터의 조합으로 시점을 맞춘 구성.
