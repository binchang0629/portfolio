# V50 문구와 상세 화면 정리

- 책: 일반적인 디자인 원칙 대신 네 프로젝트의 실제 작업 기록. 기록에서 해당 프로젝트로 이동 가능.
- 메모: 코레일·식물 웹앱·포트폴리오의 남은 작업. 별도 목록 화면으로 연결.
- 상세: 태그와 반복 카드 대신 제목, 역할, 진행 상태, 짧은 설명, 작업 목록을 배치. 프로젝트에는 원래 목록으로 돌아가는 버튼 제공.
- 내용: 기존에 확인한 프로젝트 자료의 범위 안에서 문장을 줄임. 새 성과·수치·개인 역할을 추가하지 않음. 개인 작업은 작업 중, 왈가왈BOT은 발표용 UI 범위 명시.
- AI 사용 사실은 브랜딩 과정 설명에 유지. 렌더 이미지 사용과 인터랙션 구현을 구분.
- 전 화면 Pretendard Variable 유지. 변경 전 파일은 docs/asset-history/v49-before-content-redesign에 보존.

검증: lint와 build 통과. PC 1440×960·모바일 390×844에서 42개 화면 상태 확인. 모든 상세 화면 가로 넘침 없음, Pretendard Variable 로딩 확인. 프로젝트 뒤로 가기, 책 기록 연결, 메모, 이메일 링크, 보관·꺼내기, Escape 닫기와 초점 복귀 정상.
