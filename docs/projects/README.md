코레일은 사용자 설명과 이력서, 모바일 웹앱은 제공된 Figma의 기획·화면 텍스트를 근거로 작성했습니다. 두 작업은 현재 작업 중이며, 카세트 브랜딩 포트폴리오는 별도의 04 BRANDING 작업입니다.

추가 확인: 코레일 Figma와 최신 UI, 모바일 웹앱 정식 이름·기준 버전, 각 작업의 기간·직접 담당 범위·구현 상태.

미정·확인 필요는 내부 작업 표시입니다. 이 문서가 웹사이트에 자동 공개되는 것은 아닙니다.
