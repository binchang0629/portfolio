# V52 왼쪽 플레이어 · 오른쪽 설명 페이지

- 재생하면 책상에서 읽기 화면으로 전환. 기존 플레이어를 공유하는 이동 효과, 설명 페이지의 짧은 등장, 테이프 교체 시 180ms 페이드, 본문 항목의 가벼운 등장 효과 적용.
- 설명은 시간에 따라 숨기거나 자동으로 넘기지 않음. 스크롤 위치에 따라 코일 양·릴 각도·테이프 띠 이동을 같은 계산으로 갱신. 한 화면에 모두 표시되는 짧은 내용은 전체 표시 상태로 계산.
- 읽기 화면 상자는 01~05를 각 번호 칸에 고정. 6·7번은 빈 칸. 현재 재생 중인 테이프의 칸에는 빈 케이스만 표시. 교체하면 이전 테이프가 자기 칸으로 돌아옴.
- 상자에서 클릭 또는 드래그로 교체. 드래그 중 꺼낸 칸은 비어 보임. 플레이어에 놓을 수 있을 때 테두리 표시. 다른 곳에 놓거나 취소하면 원래 칸으로 돌아옴.
- 읽기 화면에는 나머지 테이프를 선택 상자로 모아 보여 줌. 책상으로 돌아갈 때 별도 책상 위치와 보관 배열을 유지하고 현재 테이프를 꺼냄.
- 이전·다음, 재생·정지, 프로젝트 보기·목록 돌아가기, 연락, Escape로 책상 복귀 지원.
- 모바일은 상단 소형 플레이어와 접을 수 있는 상자. 본문은 아래에서 자유롭게 스크롤.
- Pretendard Variable과 #EAF2FF 책상 색 유지. 동작 줄이기 설정에서는 이동·등장·릴 회전 효과 생략.
- 변경 전 소스는 docs/asset-history/v51-before-reader에 보존.
