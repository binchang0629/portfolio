# V41 투명 케이스 보관

- 7칸 탑뷰 보관함 유지. 테이프의 잘린 사진 대신 별도 SVG 케이스 컴포넌트 사용.
- 케이스 폭 116, 길이 742. 투명 외곽, 접합선, 경첩, 잠금턱, 파스텔 책등 라벨을 분리.
- 테이프를 꺼내도 빈 케이스가 남음. 빈 케이스 클릭 또는 메뉴에서 보관 시 원래 케이스로 반환.
- 다른 빈 칸에 끌어 넣으면 케이스 위치도 함께 이동. 사용 중인 칸에 넣으면 비어 있는 칸 사용.
- 테이프만 플레이어에 삽입. 케이스가 플레이어에 들어가지 않음.
- 초기화하면 기존 책상 배치와 빈 보관함으로 돌아감.

- 보관된 테이프를 포인터로 직접 끌어 꺼내기. 케이스는 남고, 플레이어·다른 칸·책상으로 이동 가능. 취소 시 원래 케이스 복귀.
